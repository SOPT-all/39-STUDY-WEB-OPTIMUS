# 옵티머스 5주차 발표 페이지

청록·라임 포인트와 밝은 배경으로 구성한 17개 화면의 정적 발표 페이지입니다.
API 키나 서버 없이 실행되며, 화면의 동작 예시는 실제 API 호출과 구분해 표시했습니다.

## 배포된 페이지

[발표 페이지 열기](https://optimus-pr-summary-talk-minsik.outgoinghatch4.chatgpt.site)

본인 ChatGPT 계정으로 로그인하는 비공개 배포입니다. 화면 공유로 발표할 수 있습니다.

## 실행

저장소 루트에서 실행합니다.

```bash
python3 -m http.server 8035 --bind 127.0.0.1 --directory docs/pr-summary-presentation
```

브라우저에서 `http://127.0.0.1:8035`를 엽니다.

- 좌우 방향키 또는 이전·다음 버튼: 화면 이동
- `N` 또는 발표 메모 버튼: 해당 화면의 설명 메모
- 목차: 원하는 화면으로 바로 이동
- 주소의 `#11` 같은 해시: 특정 화면부터 시작

모바일에서는 내용을 세로로 읽을 수 있습니다. 메모 입력 중에는 방향키가 화면 이동을 일으키지 않습니다.

## 구성

`index.html`은 페이지 틀, `style.css`는 색상과 배치, `app.js`는 화면 내용과 상호작용입니다.
`source.js`는 발표에서 보여주는 실제 코드 일부를 정적으로 담았습니다. 운영 코드가 바뀌면 내용도 함께 갱신해야 합니다.

화면 안의 초안 적용·이벤트 선택·단계 보기 기능은 설명용 브라우저 예시입니다.
실제 검증 결과는 PR #23·#24와 Actions 실행 링크로 연결했습니다.
